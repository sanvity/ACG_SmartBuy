# ACG Films & Foils — Procurement Intelligence Frontend

This folder contains the React + Vite web application for the ACG Raw Material Price Prediction & Procurement Decision Support System.

For full project documentation, features, and setup instructions, please see the main project [README.md](../README.md).

## Quick Start

```bash
npm install
npm run dev -- --port 3000 --host
```

Open [http://localhost:3000/](http://localhost:3000/) to view the live application.
